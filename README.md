## What I work on

The website brings together product and account pages, guides, updates, videos and community resources. My work covers interface design, frontend development, interactions and ongoing performance improvements.

The latest refresh returns to the classic Bari Plux identity and background, paired with Liquid Glass cards. Work on responsive layouts, navigation, optimization and web standards continues alongside the software.

**Technologies:** HTML, CSS and JavaScript, with supporting services and automated checks. No unverified performance scores are claimed here.
